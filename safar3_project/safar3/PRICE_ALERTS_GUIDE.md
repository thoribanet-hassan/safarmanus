# 🔔 نظام مراقبة أسعار الرحلات - Price Alert System

## نظرة عامة

تم تطوير نظام متقدم لمراقبة أسعار الرحلات مع تتبع دقيق للتغييرات والنسب المئوية.

---

## الميزات الجديدة

### 1. التحقق من المتطلبات ✅

قبل إنشاء أي تنبيه، النظام يتحقق من:
- ✅ **من** (Origin - IATA code)
- ✅ **إلى** (Destination - IATA code)  
- ✅ **تاريخ المغادرة** (Departure Date - YYYY-MM-DD)

**السلوك عند النقص:**
```
المستخدم: راقب أسعار الرحلات من الرياض

النظام:
📅 متى تريد مراقبة أسعار الرحلة من الرياض إلى ؟
❌ يرجى تحديد الوجهة
```

---

### 2. منع التكرار 🚫

النظام يمنع إنشاء تنبيهات مكررة لنفس المسار والتاريخ:

```
المستخدم: راقب سعر رحلة من الرياض إلى جدة غداً
النظام: ✅ تم إنشاء التنبيه

المستخدم: راقب سعر رحلة من الرياض إلى جدة غداً
النظام: ⚠️ تنبيه مماثل موجود بالفعل
[عرض التنبيه الحالي]
```

---

### 3. حساب السعر المستهدف التلقائي 🎯

عند إنشاء تنبيه:
- يبحث النظام عن السعر الحالي
- يحدد السعر المستهدف = **85% من السعر الحالي**
- يحسب النسبة المئوية للفرق

**مثال:**
```
السعر الحالي: 1000 SAR
السعر المستهدف: 850 SAR (15% أقل)
الحالة: أعلى بـ 17.6%
```

---

### 4. تتبع تغييرات الأسعار 📊

النظام يتعرف على ثلاثة حالات:

#### أ) السعر وصل للهدف ✅
```
🎉 السعر وصل للهدف!
RUH → JED: 850 SAR
```

#### ب) السعر ارتفع 📈
```
⬆️ السعر ارتفع بنسبة 12.5%
(800 → 900 SAR)
```

#### ج) السعر انخفض 📉
```
⬇️ السعر انخفض بنسبة 8.3%
(1200 → 1100 SAR)
```

---

### 5. صيغة العرض الموحدة 📋

كل تنبيه يُعرض بهذا التنسيق:

```
🔔 تنبيه سعر لرحلة (JED → DXB)
━━━━━━━━━━━━━━━━━
📅 التاريخ: 2025-11-26
💰 السعر الحالي: 890 SAR
🎯 هدفك: 750 SAR
📊 الحالة: أعلى بـ 18.7%

سنُعلمك عندما يصل السعر للهدف أو ينخفض!
```

## البنية التقنية

### الملفات الجديدة

#### `src/services/priceAlertService.ts`

**الواجهات:**
```typescript
interface PriceAlert {
    id: string;
    from: string;
    to: string;
    date: string;
    targetPrice: number;
    currentPrice?: number;
    status: 'active' | 'reached' | 'cancelled';
}

interface PriceChange {
    oldPrice: number;
    newPrice: number;
    changePercent: number;
    status: 'increased' | 'decreased' | 'stable' | 'reached';
}
```

**الدوال الرئيسية:**
- `createPriceAlert()` - إنشاء تنبيه جديد
- `getActiveAlerts()` - جميع التنبيهات النشطة
- `getAlertForRoute()` - تنبيه لمسار معين
- `updateAlertPrice()` - تحديث السعر وحساب التغيير
- `formatAlertMessage()` - تنسيق رسالة التنبيه
- `cancelAlert()` - إلغاء تنبيه

---
