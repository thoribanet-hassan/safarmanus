
### ✅ تحويل المدن إلى IATA:

## سلوك البرنامج الكامل 🎯

### سيناريو 1: بحث ناجح
```
1. المستخدم يدخل: من="الرياض", إلى="جدة", تاريخ="2025-11-30"
2. النظام يحول: "الرياض" → RUH, "جدة" → JED
3. النظام يبحث في Backend
4. وجد 12 رحلة
5. رتب حسب السعر
6. عرض أفضل 3 رحلات ✅
```

### سيناريو 2: لا نتائج في التاريخ المحدد
```
1. المستخدم يدخل: من="RUH", إلى="DXB", تاريخ="2025-12-25"
2. النظام يبحث في Backend → لا نتائج
3. النظام يبحث في 2025-12-24 → وجد 4 رحلات
4. النظام يبحث في 2025-12-26 → وجد 3 رحلات
5. دمج 7 رحلات
6. رتب حسب السعر
7. عرض أفضل 3 رحلات ✅
```

### سيناريو 3: خطأ في الخادم
```
1. المستخدم يدخل بيانات صحيحة
2. النظام يحاول الاتصال بالـ Backend
3. الخادم لا يستجيب (timeout, network error, 500, etc.)
4. النظام: console.error('Backend Error...')
5. النظام للمستخدم: "الخدمة معلّقة مؤقتاً… جرّب بعد لحظات."
6. الواجهة تبقى تعمل ✅
7. المستخدم يمكنه المحاولة مرة أخرى ✅
```

### سيناريو 4: لا نتائج حتى مع البدائل
```
1. المستخدم يدخل مسار نادر جداً
2. النظام يبحث في التاريخ المحدد → لا نتائج
3. النظام يبحث في اليوم قبل → لا نتائج
4. النظام يبحث في اليوم بعد → لا نتائج
5. النظام: "ما لقينا نتائج… تبغاني أدور بدائل؟"
6. الواجهة تبقى تعمل ✅
```
